# DED_CORE_V4 - Универсальная система управления зажиганием

[![PlatformIO](https://img.shields.io/badge/PlatformIO-ESP32-blue.svg)](https://platformio.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Version](https://img.shields.io/badge/Version-0.0.1-red.svg)](src/DED_CORE_V4.ino)

**DED_CORE_V4** - это программируемый блок управления зажиганием (ECU) на базе ESP32 с универсальной поддержкой различных типов двигателей и веб-интерфейсом для настройки.

### ⚠️ ВАЖНО ПОНИМАТЬ ЧТО ЭТО НЕ ЛЕГАСИ КОД ОТ DED BOX. ЭТО НОВЫЙ КОД НА БАЗЕ ПРОШЛОГО ЛЕГАСИ. Я ЕЩЕ НЕ ВЫЧИСТИЛ ЕГО ПОЛНОСТЬЮ НЕ ВЕЗДЕ УСПЕЛ СДЕЛАТЬ РЕФАКТОРИНГ, НО Я СТРЕМЛЮСЬ К ЭТОМУ И ОН УЖЕ СОБИРАЕТСЯ И УЖЕ МОЖНО ИЗУЧИТЬ ЕГО ЧТО БЫ ПОНЯТЬ КАК ЭТО РАБОТАЕТ.

## 🚀 Основные возможности

- **Универсальная поддержка двигателей** - настраиваемые карты зажигания для любого ДВС
- **3 независимые карты** - быстрое переключение между режимами
- **Веб-интерфейс** - удобная настройка через браузер
- **Многоуровневая отсечка** - 4 типа защиты двигателя
- **Real-time мониторинг** - отслеживание параметров в реальном времени
- **WiFi подключение** - беспроводная конфигурация
- **Обновление по воздуху** - OTA обновления прошивки

## 📋 Поддерживаемые двигатели

Система поддерживает любые типы двигателей через настраиваемые карты зажигания и модульную систему.

## 🛠️ Быстрый старт

### Требования
- ESP32 Dev Board
- Датчик положения коленвала
- Датчик дроссельной заслонки
- Катушка зажигания

### Установка
1. Клонировать репозиторий
2. Открыть в PlatformIO
3. Скомпилировать и прошить
4. Подключиться к WiFi точке `DED_BOX_V4` (пароль: 162534Bnm123q)
5. Открыть браузер по адресу `192.168.4.1`

### Первая настройка
1. Выберите тип карты (7/12/22 точки)
2. Настройте базовые параметры зажигания
3. Сохраните конфигурацию
4. Проверьте работу двигателя

## ⚙️ Конфигурация

### Типы карт зажигания
- **Type 0** - 7 точек (базовая настройка)
- **Type 1** - 12 точек (средняя точность)
- **Type 2** - 22 точки (максимальная точность)

### Система отсечек
1. **Системная отсечка** - основной порог RPM
2. **Отсечка Карты 1** - индивидуальный порог
3. **Отсечка Карты 2** - индивидуальный порог
4. **Отсечка Карты 3** - индивидуальный порог
