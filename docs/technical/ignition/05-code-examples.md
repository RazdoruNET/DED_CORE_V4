# 05. Примеры кода с контекстом мотора

Этот раздел предоставляет полные, заменяемые примеры кода с практическим контекстом мотора для системы зажигания DED_CORE_V4.

## 5.1 Адаптивный QuickShifter

**Контекст:** Настраивает длительность блокировки искры на основе оборотов двигателя для более плавных переключений на разных скоростях.

```cpp
// В QuickShifter.h
void handleQuickShifterControllPin() {
    int quickshifter = digitalRead(quickshifter_pin);
  
    if (quickshifter == LOW) {
        if (quickshifter != quickshifter_proces) {
            // Адаптивное время: выше RPM = короче время блокировки
            // Базовое QS_time при 10000 RPM, обратная шкала
            int adaptive_qs_time = QS_time * (10000 / max(RPM, 1000));
            
            // Ограничить разумными пределами (30мс до 150мс)
            adaptive_qs_time = constrain(adaptive_qs_time, 30, 150);
            
            QS_start = micros() + (adaptive_qs_time * 1000);
        }
    }
  
    quickshifter_proces = quickshifter;
}
```

**Использование:** Замените существующую `handleQuickShifterControllPin()` на эту версию. Адаптивный алгоритм обеспечивает:
- Более короткое время блокировки на высоких RPM (быстрые переключения)
- Более длительное время блокировки на низких RPM (более полное зацепление передачи)
- Автоматическую настройку без ручной настройки для каждой передачи

## 5.2 Сплайн-интерполяция угла

**Контекст:** Более плавные переходы угла между точками карты, особенно полезно для карт с высоким разрешением.

```cpp
// В Ignition.h, добавить вспомогательную функцию
float splineInterpolate(float x, float x0, float x1, float y0, float y1) {
    float t = (x - x0) / (x1 - x0);
    
    // Сплайн Эрмита для плавных переходов
    float t2 = t * t;
    float t3 = t2 * t;
    
    float h1 = 2*t3 - 3*t2 + 1;
    float h2 = -2*t3 + 3*t2;
    float h3 = t3 - 2*t2 + t;
    float h4 = t3 - t2;
    
    // Простой случай: линейный с плавным сглаживанием
    return y0 + (y1 - y0) * (3*t2 - 2*t3);
}

// В handleAngle(), заменить вызов map()
if (RPM >= rpmsArr[i] && RPM <= rpmsArr[i+1]) {
    Advance_angle = splineInterpolate(RPM, rpmsArr[i], rpmsArr[i+1], 
                                      anglesArr[i], anglesArr[i+1]);
}
```

**Преимущества:**
- Более плавные переходы угла
- Уменьшает резкие изменения на границах карты
- Лучший отклик дросселя

## 5.3 Фильтр Калмана для RPM

**Контекст:** Обеспечивает измерение RPM устойчивое к шуму с минимальной задержкой, идеально для гоночных приложений.

```cpp
// В Sensors.h, добавить глобальные переменные
float kalman_rpm = 0;
float kalman_p = 1.0;  // Ковариация оценки
float kalman_q = 0.05; // Шум процесса (настроить для отзывчивости)
float kalman_r = 0.5;  // Шум измерения (настроить для фильтрации)

void handleRpm() {
    // ... существующий расчет timePerDegree ...
    
    int rawRPM = 60000000 / timePerDegree;
    
    if (firstRpm) {
        kalman_rpm = rawRPM;
        firstRpm = false;
    } else {
        // Прогноз фильтра Калмана
        kalman_p = kalman_p + kalman_q;
        
        // Обновление фильтра Калмана
        float kalman_k = kalman_p / (kalman_p + kalman_r);
        kalman_rpm = kalman_rpm + kalman_k * (rawRPM - kalman_rpm);
        kalman_p = (1 - kalman_k) * kalman_p;
        
        RPM = (int)kalman_rpm;
    }
}
```

**Настройка:**
- Увеличьте `kalman_q` для более быстрого отклика (больше шума)
- Увеличьте `kalman_r` для большей фильтрации (больше задержки)
- Типичные значения: q=0.05, r=0.5 для сбалансированной производительности

## 5.4 Корректировка угла по температуре

**Контекст:** Уменьшает угол опережения зажигания при высокой температуре двигателя для предотвращения детонации и защиты двигателя.

```cpp
// В Ignition.h, добавить в handleAngle()
float tempCorrection = 0;

// Корректировка по температуре: уменьшить угол выше 80°C
if (Termo > 80) {
    // Вычесть 0.1 градуса на градус выше 80°C
    tempCorrection = (Termo - 80) * 0.1;
    
    // Максимальная корректировка 5 градусов
    tempCorrection = min(tempCorrection, 5.0);
}

// Обогащение холодного двигателя: добавить угол ниже 40°C
if (Termo < 40 && Termo > 0) {
    // Добавить 0.05 градуса на градус ниже 40°C
    tempCorrection = tempCorrection - ((40 - Termo) * 0.05);
}

Advance_angle = Advance_angle - tempCorrection;

// Убедиться, что угол не становится отрицательным
Advance_angle = max(Advance_angle, 0);
```

**Поведение:**
- **Горячий двигатель (>80°C):** Постепенно уменьшает угол для предотвращения детонации
- **Холодный двигатель (<40°C):** Увеличивает угол для лучшей производительности при холодном запуске
- **Нормальный диапазон (40-80°C):** Корректировка не применяется
