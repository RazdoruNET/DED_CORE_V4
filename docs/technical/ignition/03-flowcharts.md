# 03. Блок-схемы

Этот раздел содержит блок-схемы для ключевых алгоритмов системы зажигания DED_CORE_V4.

## 3.1 Основной цикл - handleMoto()

```
┌─────────────────────────────────┐
│         handleMoto()            │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│      handlePin()                │
│  - Чтение датчика ВМТ           │
│  - Чтение ADC дросселя          │
│  - Чтение пина QuickShifter     │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│      handleRpm()                │
│  - Расчет timePerDegree         │
│  - Расчет RPM                   │
│  - Применение фильтра шума      │
│  - Детектирование остановки      │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│      handleAngle()              │
│  - Получение базового угла      │
│  - Интерполяция между точками   │
│  - Корректировка по дросселю    │
│  - Ограничение на высоких RPM   │
│  - Расчет времени искры         │
│  - Управление сервоприводом     │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│      handleIgnition()           │
│  - Детектирование фронта        │
│  - Расчет nextFlashMicro        │
│  - Установка состояния выхода   │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│      handleFlash()              │
│  - Проверка времени искры       │
│  - Активация катушки            │
│  - Деактивация после длительности│
│  - Обработка блокировки QS      │
└──────────────┬──────────────────┘
               │
               ▼
         Цикл к handleMoto()
```

## 3.2 Алгоритм расчета угла - handleAngle()

```
┌─────────────────────────────────┐
│      handleAngle()              │
└──────────────┬──────────────────┘
               │
               ▼
       ┌───────────────┐
       │ RPM <= minRPM?│
       └───────┬───────┘
               │
      Да ──────┴───── Нет
       │              │
       ▼              ▼
  ┌─────────┐  ┌──────────────────┐
  │ Возврат │  │ Получить тип     │
  │ (нет искры)│  │ карты          │
  └─────────┘  │ (0=7тч, 1=12тч, │
               │  2=22тч)         │
               └────────┬─────────┘
                        │
                        ▼
               ┌──────────────────┐
               │ Найти индекс RPM │
               │ в rpmsArr[]      │
               └────────┬─────────┘
                        │
                        ▼
               ┌──────────────────┐
               │ Линейная         │
               │ интерполяция     │
               │ угла между       │
               │ точками карты     │
               └────────┬─────────┘
                        │
                        ▼
               ┌──────────────────┐
               │ ANGLE_ADVANCE?  │
               └────────┬─────────┘
                        │
               Да ──────┴───── Нет
                │              │
                ▼              │
       ┌────────────────┐      │
       │ Применить      │      │
       │ корректировку  │      │
       │ по дросселю     │      │
       └────────┬───────┘      │
                │              │
                └──────┬───────┘
                       │
                       ▼
              ┌──────────────────┐
              │ RPM >= max_rpm?  │
              └────────┬─────────┘
                       │
              Да ──────┴───── Нет
               │              │
               ▼              │
      ┌────────────────┐      │
      │ Вычесть        │      │
      │ max_rpm_kiker  │      │
      └────────┬───────┘      │
               │              │
               └──────┬───────┘
                      │
                      ▼
             ┌──────────────────┐
             │ Рассчитать       │
             │ diffAngle =     │
             │ Init_angle -    │
             │ Advance_angle   │
             └────────┬─────────┘
                      │
                      ▼
             ┌──────────────────┐
             │ Рассчитать       │
             │ diffMicros =     │
             │ diffAngle *      │
             │ (timePerDegree/360)│
             └────────┬─────────┘
                      │
                      ▼
             ┌──────────────────┐
             │ SERVO включен?   │
             └────────┬─────────┘
                      │
             Да ──────┴───── Нет
              │              │
              ▼              │
     ┌────────────────┐     │
     │ Управление     │     │
     │ сервоприводом  │     │
     │ (тип 0 или 1)  │     │
     └────────┬───────┘     │
              │             │
              └─────┬───────┘
                    │
                    ▼
           ┌──────────────────┐
           │ Установить       │
           │ nextFlashMicro = │
           │ oldRpmMicro +   │
           │ diffMicros      │
           └──────────────────┘
```

## 3.3 Алгоритм фильтрации RPM

```
┌─────────────────────────────────┐
│      handleRpm()                │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ Измерение времени между        │
│ импульсами                      │
│ timePerDegree = текущий - прошлый│
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│ Расчет сырого RPM               │
│ rawRPM = 60000000 / timePerDegree│
└──────────────┬──────────────────┘
               │
               ▼
       ┌───────────────┐
       │ Первое        │
       │ чтение?       │
       └───────┬───────┘
               │
      Да ──────┴───── Нет
       │              │
       ▼              ▼
  ┌─────────┐  ┌──────────────────┐
  │ RPM =   │  │ Рассчитать       │
  │ rawRPM  │  │ изменение       │
  └─────────┘  │ в процентах     │
               │ change = abs((raw│
               │ - prev) * 100 /  │
               │ prev)            │
               └────────┬─────────┘
                        │
                        ▼
               ┌──────────────────┐
               │ change <= filter?│
               └────────┬─────────┘
                        │
               Да ──────┴───── Нет
                │              │
                ▼              ▼
       ┌────────────────┐ ┌──────────┐
       │ RPM = rawRPM   │ │ Игнорир. │
       │ prevRPM = rawRPM│ │ (шум)    │
       └────────────────┘ └──────────┘
```
