# 02. Временные диаграммы

Этот раздел содержит временные диаграммы для ключевых операций системы зажигания DED_CORE_V4.

## 2.1 Диаграмма работы датчика ВМТ

```
Время →
     ┌─────┐     ┌─────┐     ┌─────┐
     │     │     │     │     │     │
─────┘     └─────┘     └─────┘     └─────  Сигнал датчика
     ↑     ↑     ↑     ↑     ↑
     t0    t1    t2    t3    t4

t1 - t0 = timePerDegree
RPM = 60000000 / (t1 - t0)

Детектирование остановки двигателя:
Если (t_current - t_last) > 500мс → RPM = 0
```

**Ключевые события:**
- Фронты импульсов датчика запускают расчет RPM
- Время между импульсами измеряется в микросекундах
- Таймаут 500мс указывает на остановку двигателя

## 2.2 Диаграмма синхронизации зажигания

```
Угол коленвала (градусы) →
0° (ВМТ)    360° (ВМТ)
    │         │
    │         │
    └─────────┘
     ↑         ↑
     │         │
   Init_angle  │
     │         │
     ↓         │
  Advance_angle│
     │         │
     ↓         │
  Точка искры  │
     │         │
     ↓         │
  Init_flash_time
     │
     ↓
  Длительность импульса катушки

Временная шкала:
Датчик ВМТ → [diffMicros] → Запуск искры → [Init_flash_time] → Катушка OFF
```

**Последовательность:**
1. Обнаружен импульс датчика ВМТ
2. Ожидание `diffMicros` микросекунд
3. Запуск искры (активация катушки)
4. Поддержание катушки активной в течение `Init_flash_time` микросекунд
5. Деактивация катушки

## 2.3 Диаграмма работы QuickShifter

```
Время →
Нормальная работа:
     ┌─────┐     ┌─────┐     ┌─────┐
─────┘     └─────┘     └─────┘     └─────  Сигналы искры
     ↑     ↑     ↑     ↑
   Искра  Искра  Искра  Искра

QuickShifter активирован:
     ┌─────┐     ┌─────┐     ┌─────┐
─────┘     └─────┘     └─────┘     └─────  Сигналы искры
     ↑     X     X     X     ↑
   Искра  Заблокировано QS
           ↑
           QS_start
           │
           └─── QS_time (мс) ───┘
```

**Работа:**
- Пин QuickShifter переходит в LOW при обнаружении переключения передачи
- `QS_start` устанавливается на текущее время + `QS_time` миллисекунд
- Все искры блокируются до истечения времени `QS_start`
- Типичное QS_time: 50-100мс

## 2.4 Диаграммы работы сервопривода

**Тип 0: Позиция по RPM (по карте)**
```
RPM →
0    2000  4000  6000  8000  10000  12000
│     │     │     │     │     │      │
│     │     │     │     │     │      │
└─────┴─────┴─────┴─────┴─────┴──────┘
Позиция сервопривода (градусы) из карты
```

**Тип 1: Включение/выключение по RPM**
```
RPM →
0    2000  4000  6000  8000  10000  12000
│     │     │     │     │     │      │
│     │     │     │     │     │      │
└─────┴─────┴─────┴─────┴─────┴──────┘
           ↑
         Servo_rpm
           │
           └──→ Servo_percent (например, 50%)
```

**Тип 0:** Позиция сервопривода следует кривой карты RPM  
**Тип 1:** Сервопривод открывается на фиксированный процент при превышении порога RPM
