# Аппаратная документация DED_CORE_V4

## Подключение оборудования

### Распиновка ESP32
```
GPIO 16  - Датчик положения коленвала (Hall sensor)
GPIO 17  - Быстрый переключатель передач (Quickshifter)
GPIO 19  - Выход на катушку зажигания (Ignition coil)
GPIO 32  - Переключение карты вверх (Cart select up)
GPIO 33  - Переключение карты вниз (Cart select down)
GPIO 35  - Датчик дроссельной заслонки (Throttle sensor)
```

### Схема подключения
```
ESP32 Board
├── GPIO 16 → Датчик коленвала
│   ├── VCC → 3.3V
│   ├── GND → GND
│   └── OUT → GPIO 16
├── GPIO 17 → Быстрый переключатель
│   ├── VCC → 3.3V
│   ├── GND → GND
│   └── IN → GPIO 17 (с подтяжкой)
├── GPIO 19 → Катушка зажигания
│   ├── GPIO 19 → Транзистор
│   ├── Транзистор → Катушка
│   └── Катушка → Свеча
├── GPIO 32 → Кнопка карты вверх
│   ├── GPIO 32 → Кнопка
│   └── Кнопка → GND
├── GPIO 33 → Кнопка карты вниз
│   ├── GPIO 33 → Кнопка
│   └── Кнопка → GND
└── GPIO 35 → Датчик дросселя
    ├── VCC → 3.3V
    ├── GND → GND
    └── OUT → GPIO 35
```

## Требования к компонентам

### ESP32 плата
- **Модель**: ESP32 DevKit v1 или аналогичная
- **Память**: минимум 4MB Flash, 520KB RAM
- **WiFi**: встроенный модуль 802.11 b/g/n
- **Питание**: 3.3V, 500mA макс.

### Датчик положения коленвала
- **Тип**: Hall эффект датчик
- **Напряжение**: 3.3V-5V
- **Частота**: до 20 кГц
- **Выход**: цифровой (TTL уровень)

### Датчик дроссельной заслонки
- **Тип**: Потенциометр
- **Сопротивление**: 1кОм-10кОм
- **Напряжение**: 3.3V-5V
- **Точность**: 0.1%

### Катушка зажигания
- **Тип**: Индукционная катушка
- **Сопротивление**: 0.5-3 Ом
- **Энергия**: 30-50 мДж
- **Напряжение**: до 40кВ

## Электрическая схема

### Силовая часть
```
3.3V ──┬─ ESP32
        │
        ├─ Датчик коленвала (GPIO 16)
        ├─ Датчик дросселя (GPIO 35)
        ├─ Кнопки (GPIO 32, 33)
        └─ Транзистор управления
              │
              ├─ База → GPIO 19
              ├─ Эмитер → GND

                        │

```

## Механический монтаж

### Размещение компонентов
- **ESP32**: в герметичном корпусе
- **Датчики**: на виброопорах
- **Провода**: в экранированной оплетке
- **Разъемы**: влагозащищенные

### Виброзащита
- **Платформа**: резиновые виброопоры
- **Крепление**: амортизирующие прокладки
- **Провода**: петли для компенсации вибрации
- **Корпус**: металлический для экранирования

## Тестирование оборудования

### Проверка датчиков
```cpp
// Тест датчика положения коленвала
bool testCrankshaftSensor() {
    for (int i = 0; i < 1000; i++) {
        int value = digitalRead(SENSOR_PIN);
        if (value != HIGH && value != LOW) {
            return false;
        }
        delay(1);
    }
    return true;
}

// Тест датчика дросселя
bool testThrottleSensor() {
    int min_val = 4095;
    int max_val = 0;
    
    for (int i = 0; i < 100; i++) {
        int value = analogRead(THROTTLE_PIN);
        min_val = min(min_val, value);
        max_val = max(max_val, value);
        delay(10);
    }
    
    return (max_val - min_val > 3000);
}
```

### Калибровка датчиков
```cpp
// Калибровка датчика дросселя
void calibrateThrottle() {
    Serial.println("Калибровка дросселя...");
    
    // Калибровка закрытого положения
    Serial.println("Закройте дроссель и нажмите Enter");
    while (!Serial.available());
    throttle_closed = analogRead(THROTTLE_PIN);
    
    // Калибровка открытого положения
    Serial.println("Откройте дроссель полностью и нажмите Enter");
    while (!Serial.available());
    throttle_open = analogRead(THROTTLE_PIN);
    
    Serial.print("Калибровка завершена: ");
    Serial.print(throttle_closed);
    Serial.print(" - ");
    Serial.println(throttle_open);
}
```

## Поиск неисправностей

### Типичные проблемы

#### Нет сигнала с датчика коленвала
**Причины:**
- Обрыв провода
- Неисправность датчика
- Неправильное питание

**Решение:**
1. Проверьте напряжение питания датчика
2. Проверьте целостность проводов
3. Замените датчик

#### Помехи на датчике
**Причины:**
- Отсутствие экранирования
- Близость к высоковольтным проводам
- Плохой контакт

**Решение:**
1. Используйте экранированный кабель
2. Удалите от высоковольтных проводов
3. Проверьте качество контактов

#### Проблемы с питанием ESP32
**Причины:**
- Недостаточное напряжение
- Просадки напряжения при нагрузке
- Неисправность стабилизатора

**Решение:**
1. Проверьте напряжение питания (должно быть 3.3V)
2. Используйте конденсаторы для фильтрации
3. Замените стабилизатор
