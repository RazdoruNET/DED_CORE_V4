# Архитектура проекта DED_CORE_V4

## Обзор

DED_CORE_V4 - это система управления зажиганием для мотоциклов на базе ESP32, которая обеспечивает точное управление углом опережения зажигания в зависимости от оборотов двигателя и других параметров.

## Системная архитектура

### Основные компоненты

#### 1. Конфигурация и переменные (`config/`)
- **PROPS.h** - Объявления глобальных переменных (extern)
- **PROPS_DEF.h** - Определения глобальных переменных
- **PINS_DEF.h** - Определения пинов ESP32
- **CONFIG.h** - Конфигурационные константы
- **ARRAYS_DEF.h** - Массивы данных для разных типов карт

#### 2. Инициализация системы (`core/init/`)
- **SYSTEM_INIT.h** - Инициализация железа и задач
- Инициализация последовательного порта и пинов
- Создание и запуск RTOS задач

#### 3. Управление предпочтениями (`core/preferences/`)
- **PREFERENCES_MANAGER.h** - Управление настройками в NVS
- Сохранение/загрузка конфигурации
- Управление параметрами карт

#### 4. Режим восстановления (`core/recovery/`)
- **RECOVERY_MODE.h** - Режим восстановления при сбоях
- Проверка активации через пины
- Запуск WiFi AP и веб-сервера

#### 5. Система зажигания (`core/ignition/`)
- **MOTO.h** - Основная логика управления зажиганием
- **Init.h** - Инициализация подсистемы зажигания
- **Ignition.h** - Управление искрой
- **Flash.h** - Управление вспышкой
- **Sensors.h** - Работа с датчиками
- **Utils.h** - Вспомогательные функции
- **Variables.h** - Переменные состояния системы

#### 6. Карты зажигания (`core/ignition/carts/`)
- **MOTO_CARTS.h** - Общий заголовок для всех карт
- **Angles_*.h** - Углы опережения для разных моделей
- **RPMs.h** - Таблицы оборотов для карт

#### 7. Обработчики событий (`core/handlers/`)
- **HANDLERS.h** - Основные обработчики
- **Alarm.h** - Система аварийных сигналов
- **CartSelection.h** - Выбор и переключение карт
- **QuickShifter.h** - Быстрое переключение передач

#### 8. Задачи RTOS (`core/tasks/`)
- **TASKS.h** - Общие объявления задач
- **MotoTask.h** - Задача управления зажиганием
- **ServerTask.h** - Задача веб-сервера
- **ControlTask.h** - Задача управления пинами
- **AlarmTask.h** - Задача аварийной системы

#### 9. Сетевые серверы (`servers/`)
- **WIFI_SERVER.h** - Управление WiFi точкой доступа
- **WEB_SERVER.h** - HTTP сервер для веб-интерфейса
- **WEB_SOCKET_SERVER.h** - WebSocket сервер для реального времени
- **SERVER.h** - Общие функции серверов

#### 10. Вспомогательные функции (`functions/`)
- **SOUND.h** - Управление звуковыми сигналами

## Поток выполнения программы

### 1. Инициализация (setup())
```
1. Инициализация железа (initSystemHardware)
   - Настройка Serial
   - Конфигурация пинов
   - Настройка GPIO pull-up/pull-down

2. Проверка режима восстановления
   - Если активирован → enterRecoveryMode()
   - Иначе → нормальный запуск

3. Нормальный запуск
   - Инициализация Мото (initMoto)
   - Инициализация предпочтений (initializePreferences)
   - Настройка конфигурации (setupConfiguration)
   - Запуск задач (initSystemTasks)
   - Инициализация звука (initSystemSound)

4. Основной цикл (loop())
   - Обработка Мото (handleMoto)
```

### 2. Задачи RTOS
```
TaskServerHandler (Приоритет 2, Ядро 0)
- Инициализация WiFi (initWifi)
- Инициализация WebSocket (initWebSocket)
- Инициализация веб-сервера (initServer)
- Обработка DNS запросов
- Обработка HTTP запросов

TaskControlHandler (Приоритет 1, Ядро 0)
- Обработка кнопок управления
- Обработка датчиков
- Управление переключением карт

TaskAlarmHandler (Приоритет 1, Ядро 0)
- Мониторинг аварийных ситуаций
- Обработка RPM аварий
- Управление звуковой сигнализацией
```

## Взаимодействие компонентов

### Система зажигания
- **Расчет угла опережения**: Базовый угол + корректировки
- **Управление искрой**: Временная синхронизация с ВМТ
- **Адаптивное управление**: Изменение угла в зависимости от оборотов

### Сетевой интерфейс
- **WiFi AP**: Точка доступа для настройки
- **HTTP сервер**: Веб-интерфейс конфигурации
- **WebSocket**: Обновление данных в реальном времени
- **Captive Portal**: Автоматическое перенаправление

### Система конфигурации
- **NVS хранилище**: Постоянное сохранение настроек
- **Профили карт**: Предустановленные параметры для разных моделей
- **Динамическая настройка**: Изменение параметров через веб
