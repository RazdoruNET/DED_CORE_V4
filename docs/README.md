# DED_CORE_V4 - Система управления зажиганием

## Обзор

DED_CORE_V4 - это продвинутая система управления зажиганием для мотоциклов, построенная на базе ESP32. Система обеспечивает точное управление углом опережения зажигания в зависимости от оборотов двигателя, положения дросселя и других параметров.

## Основные возможности

### 🚀 Управление зажиганием
- **Точное опережение**: Адаптивное изменение угла зажигания в зависимости от RPM
- **Множественные профили**: Поддержка различных настроек для разных типов двигателей
- **Быстрое переключение**: QuickShifter для молниеносных переключений передач
- **Динамическая корректировка**: Настройка углов в реальном времени

### 🌐 Веб-интерфейс
- **WiFi точка доступа**: Встроенный AP для настройки устройства
- **Веб-сервер**: Удобный интерфейс конфигурации через браузер
- **WebSocket**: Обновление данных в реальном времени
- **Captive Portal**: Автоматическое перенаправление на страницу настройки

### 📊 Мониторинг
- **Показания датчиков**: RPM, температура, положение дросселя
- **Визуализация**: Графическое отображение параметров
- **Логирование**: Запись критических событий

### 🛡️ Безопасность
- **Режим восстановления**: Защита от сбоев конфигурации
- **Проверка целостности**: Валидация настроек при запуске
- **Graceful degradation**: Плавное снижение функциональности при ошибках

## Быстрый старт

### 1. Подключение аппаратуры
```
ESP32 Pinout:
├── GPIO16 → Датчик ВМТ (sensor_pin)
├── GPIO17 → QuickShifter (quickshifter_pin)
├── GPIO19 → Выход на комутаток (out_pin)
├── GPIO32 → Кнопка "Вверх" (select_cart_up_pin)
├── GPIO33 → Кнопка "Вниз" (select_cart_down_pin)
└── GPIO35 → Датчик дросселя (throttle_pin)
```

### 2. Первая прошивка
1. Подключите питание к ESP32
2. Подключите датчики и исполнительные механизмы
3. Включите питание - создастся WiFi точка "DED_BOX_V4"
4. Подключитесь к WiFi сети (пароль: "162534Bnm123q")
5. Откройте браузер и перейдите на http://192.168.4.1
6. Настройте базовые параметры зажигания

## Калибровка и настройка

### 🎯 Первичная калибровка
1. **Установка базового угла**: 
   - Запустить двигатель на холостом ходу
   - Установить угол 10-15 градусов до ВМТ

2. **Настройка датчика**:
   - Проверить стабильность показаний RPM
   - Отфильтровать шумы и помехи
   - Настроить пороги срабатывания

3. **Тестирование опережения**:
   - Постепенно увеличивать угол при росте RPM
   - Контролировать детонацию по звуку
   - Настроить переходные характеристики

### ⚡ Оптимизация производительности
- **Таблица опережения**: Настройка оптимальных углов
- **Фильтрация RPM**: Сглаживание показаний датчика
- **Адаптивное управление**: Динамическая подстройка

## Устранение неисправностей

### 🔧 Частые проблемы
1. **Нет искры**:
   - Проверить соединение катушки
   - Проверить питание MOSFET
   - Проверить настройки угла

2. **Нестабильные обороты**:
   - Проверить датчик ВМТ
   - Отфильтровать помехи
   - Проверить зазор датчика

3. **Не работает WiFi**:
   - Проверить настройки AP
   - Перезагрузить устройство
   - Сбросить настройки к заводским

### 📱 Диагностика через веб-интерфейс
