# Руководство для начинающих - Основы зажигания

## Что такое зажигание?

Представьте, что двигатель - это пушка. Чтобы выстрелить (сделать рабочий ход), нужна искра в правильный момент. Зажигание - это система, которая создает эту искру.

### Простыми словами:
- **Топливо** попадает в цилиндр
- **Поршень** сжимает топливо
- **Искра** поджигает топливо
- **Взрыв** толкает поршень вниз
- **Коленвал** крутится и двигает мотоцикл

## Почему важен момент зажигания?

### Слишком ранняя искра:
- Искра появляется когда поршень еще идет вверх
- Двигатель "борется" сам с собой
- Потеря мощности и возможная поломка

### Слишком поздняя искра:
- Поршень уже идет вниз когда искра появляется
- Топливо не успевает сгореть полностью
- Двигатель не тянет, перегревается

### Идеальный момент:
- Искра появляется за немного до верхней мертвой точки
- Топливо сгорает когда поршень в верхней точке
- Максимальное давление толкает поршень вниз

## Что такое угол опережения?

**Угол опережения зажигания** - это на сколько градусов до верхней мертвой точки подается искра.

- **Низкие обороты** - нужно больше времени для горения → больший угол
- **Высокие обороты** - время горения не меняется → меньший угол
- **Нагрузка** - при открытом дросселе нужно больше времени → коррекция

## Как работает DED_CORE_V4?

### Основные компоненты:
1. **Датчик положения коленвала** - говорит где находится поршень
2. **Датчик дросселя** - говорит сколько газа вы даете
3. **ESP32** - умный мозг все рассчитывает
4. **Катушка зажигания** - создает искру

### Алгоритм работы:
1. Датчик говорит: "коленвал в положении X"
2. ESP32 смотрит: "текущие обороты Y, дроссель Z%"
3. ESP32 смотрит в таблицу: "для таких условий нужен угол A"
4. ESP32 ждет нужного момента
5. ESP32 дает команду: "сейчас подать искру"
6. Катушка создает искру в идеальный момент

## Что такое карты зажигания?

**Карта зажигания** - это таблица где записано какой угол зажигания нужен для разных оборотов.

### Пример простой карты:
| Обороты | Угол зажигания |
|----------|----------------|
| 1000     | 15°            |
| 2000     | 20°            |
| 3000     | 25°            |
| 4000     | 30°            |
| 5000     | 28°            |

### Почему разные карты?
- **Карта 1** - для города, экономия топлива
- **Карта 2** - для трассы, максимальная мощность
- **Карта 3** - для плохого бензина, безопасность

## Что такое отсечка?

**Отсечка** - это защита двигателя от слишком высоких оборотов.

### Как работает:
1. Датчик видит: "обороты слишком высокие!"
2. Система уменьшает угол зажигания
3. Мощность падает, обороты не растут
4. Двигатель не ломается

### Типы отсечки в DED_CORE_V4:
1. **Главная отсечка** - общая защита (например 10000 об/мин)
2. **Отсечка карты 1** - индивидуальная для карты 1
3. **Отсечка карты 2** - индивидуальная для карты 2
4. **Отсечка карты 3** - индивидуальная для карты 3

## Как начать пользоваться?

### Шаг 1: Подключение
- Подключите датчики к ESP32
- Подключите катушку зажигания
- Подайте питание на систему

### Шаг 2: Первый запуск
- Включите зажигание мотоцикла
- Подключитесь к WiFi "DED_BOX_V4"
- Откройте браузер по адресу 192.168.4.1

### Шаг 3: Базовая настройка
1. Выберите тип карты (7 точек для начала)
2. Установите начальный угол (обычно 35-45°)
3. Поставьте отсечку (например 10000 об/мин)
4. Сохраните настройки

### Шаг 4: Проверка
1. Заведите двигатель
2. Посмотрите на обороты на холостом ходу
3. Прослушайте работу двигателя
4. Если работает ровно - хорошо!

## Что смотреть в веб-интерфейсе?

### Основные параметры:
- **RPM** - текущие обороты двигателя
- **Угол зажигания** - сколько градусов сейчас
- **Дроссель** - как сильно открыта заслонка
- **Активная карта** - какой профиль сейчас работает

### Индикаторы:
- **Зеленый** - все в норме
- **Желтый** - внимание, проверьте параметры
- **Красный** - опасно, отсечка сработала

## Простые правила безопасности

### Никогда не делайте:
- Ставить угол больше 60° на низких оборотах
- Отключать отсечку совсем
- Игнорировать красные индикаторы
- Настраивать на горячем двигателе

### Всегда делайте:
- Начинать с консервативных углов
- Проверять настройки на холостом ходу
- Слушать как работает двигатель
- Сохранять рабочие настройки

## Частые проблемы новичков

### Двигатель не заводится:
- Проверьте подключение датчиков
- Проверьте начальный угол (не слишком маленький?)
- Проверьте питание системы

### Двигатель работает неровно:
- Проверьте фильтр RPM (может слишком большой?)
- Проверьте коррекцию по дросселю
- Проверьте состояние свечи

### Нет мощности:
- Угол зажигания слишком поздний
- Отсечка срабатывает слишком рано
- Неправильный тип карты для вашего двигателя

### Двигатель стучит:
- Угол зажигания слишком ранний
- Плохой бензин (нужно уменьшить угол)
- Проблемы с датчиком положения

## Что дальше?

После освоения основ можно:
- Настроить точные карты под ваш двигатель
- Добавить коррекцию по температуре
- Настроить быстрое переключение передач
- Использовать продвинутые функции анализа

## Помните!

Главное правило новичка: **лучше позже чем раньше**. Позднее зажигание просто снизит мощность, а раннее может сломать двигатель.

Начинайте с консервативных настроек, постепенно улучшайте результат, и всегда слушайте как работает ваш двигатель.
