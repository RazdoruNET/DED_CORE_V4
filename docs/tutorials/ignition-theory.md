## Термодинамика сгорания

### Уравнение состояния идеального газа

```
P·V = n·R·T
```

Где:
- **P** - давление (Па)
- **V** - объём (м³)
- **n** - количество вещества (моль)
- **R** - универсальная газовая постоянная = 8.314 Дж/(моль·К)
- **T** - температура (К)

### Первое начало термодинамики

```
dU = δQ - δW
```

Где:
- **dU** - изменение внутренней энергии
- **δQ** - подведённое тепло
- **δW** - совершённая работа

Для адиабатического процесса:
```
P·V^γ = constant
T·V^(γ-1) = constant
P^(1-γ)·T^γ = constant
```

Где **γ** (гамма) - показатель адиабаты:
- Для воздуха: γ = 1.4
- Для продуктов сгорания: γ = 1.3 - 1.35

### Теплота сгорания топлива

Теплота сгорания бензина (низшая):
```
Q_low = 44.4 МДж/кг
```

Теплота сгорания с учётом скрытой теплоты парообразования воды (высшая):
```
Q_high = 46.0 МДж/кг
```

### Стехиометрическое соотношение

Для бензина (C₈H₁₈):
```
C₈H₁₈ + 12.5O₂ → 8CO₂ + 9H₂O
```

Массовое стехиометрическое соотношение:
```
λ = (m_air / m_fuel) / (m_air_stoich / m_fuel_stoich)
```

Стехиометрическое соотношение для бензина:
```
AFR_stoich = 14.7:1 (по массе)
```

## Кинетика химических реакций

### Закон Аррениуса

Скорость химической реакции:
```
k = A · exp(-Ea / (R·T))
```

Где:
- **k** - константа скорости реакции
- **A** - предэкспоненциальный множитель
- **Ea** - энергия активации (Дж/моль)
- **R** - универсальная газовая постоянная
- **T** - температура (К)

### Время задержки воспламенения

Эмпирическая формула для времени задержки воспламенения (τ):
```
τ = A·p^(-n)·exp(Ea / (R·T))
```

Типичные значения для бензина:
- **A** = 3.45·10⁻³ мс
- **n** = 1.18
- **Ea** = 31800 кДж/кмоль

### Скорость распространения фронта пламени

Скорость ламинарного горения:
```
S_L = S_L0 · (T_u / T_0)^α · (p / p_0)^β
```

Где:
- **S_L** - скорость ламинарного горения при текущих условиях
- **S_L0** - скорость ламинарного горения при стандартных условиях
- **T_u** - температура несгоревшей смеси
- **T_0** = 298 К (стандартная температура)
- **p** - текущее давление
- **p_0** = 101325 Па (стандартное давление)
- **α** = 1.8 - 2.3 (температурный показатель)
- **β** = -0.16 - -0.22 (показатель давления)

Типичная скорость ламинарного горения для бензина:
```
S_L0 = 0.38 - 0.45 м/с (при λ = 1.0)
```

Скорость турбулентного горения:
```
S_T = S_L · (1 + C · u' / S_L)
```

Где:
- **S_T** - скорость турбулентного горения
- **u'** - скорость турбулентных пульсаций
- **C** = 1.0 - 2.0 (эмпирическая константа)

## Расчёт угла опережения зажигания

### Время сгорания смеси

Полное время сгорания:
```
t_burn = t_ignition_delay + t_flame_propagation
```

Время распространения пламени:
```
t_flame_propagation = r_max / S_T
```

Где **r_max** - максимальный радиус фронта пламени в камере сгорания.

### Угол опережения зажигания (MBT - Maximum Brake Torque)

Оптимальный угол опережения зажигания:
```
θ_MBT = 360° · (t_burn / t_cycle)
```

Где время цикла:
```
t_cycle = 60 / (RPM / 2) = 120 / RPM (для 4-тактного двигателя)
```

Угол в градусах ПКВ:
```
θ_MBT = 360° · (t_burn · RPM / 120) = 3° · t_burn · RPM
```

### Зависимость от оборотов

С учётом изменения скорости турбулентного горения:
```
S_T ∝ RPM^0.5
t_burn ∝ RPM^(-0.5)
θ_MBT ∝ RPM^0.5
```

Эмпирическая зависимость:
```
θ_MBT = θ_0 · (RPM / RPM_0)^0.5
```

### Зависимость от нагрузки (наполнения)

Коэффициент наполнения:
```
η_v = m_air / (ρ_air · V_d)
```

Где:
- **m_air** - масса воздуха в цилиндре
- **ρ_air** - плотность воздуха на впуске
- **V_d** - рабочий объём цилиндра

Корректировка угла по нагрузке:
```
θ_load = θ_MBT · (1 - k_load · (1 - η_v))
```

Где **k_load** = 0.3 - 0.5 (эмпирический коэффициент)

### Зависимость от состава смеси (λ)

Оптимальный угол для разных λ:
```
θ_λ = θ_MBT · f(λ)
```

Эмпирическая функция:
```
f(λ) = 1 + k_λ · (λ - 1)^2
```

Где **k_λ** = 0.5 - 1.0 (зависит от конструкции камеры сгорания)

## Волновые процессы в камере сгорания

### Скорость звука в газе

```
c = √(γ · R · T / M)
```

Где:
- **c** - скорость звука (м/с)
- **γ** - показатель адиабаты
- **R** - универсальная газовая постоянная
- **T** - температура (К)
- **M** - молярная масса газа (кг/моль)

Для воздуха при 300 К:
```
c = √(1.4 · 8.314 · 300 / 0.029) ≈ 347 м/с
```

### Частота детонации

Частота детонационных волн:
```
f_det = c / (4 · L)
```

Где **L** - характерный размер камеры сгорания.

Для типичного двигателя:
```
L ≈ 0.05 м
c ≈ 800 м/с (при высокой температуре)
f_det ≈ 800 / (4 · 0.05) = 4000 Гц
```

### Критерий детонации

Число Кнудсена для детонации:
```
Kn = λ_mfp / L_char
```

Где:
- **λ_mfp** - длина свободного пробега молекул
- **L_char** - характерный размер

Критическое число Маха для детонации:
```
Ma_crit = √(2 / (γ + 1))
```

Для воздуха:
```
Ma_crit = √(2 / 2.4) ≈ 0.91
```

## Теплоотдача и теплопотери

### Число Нуссельта

Для теплоотдачи в цилиндре:
```
Nu = C · Re^m · Pr^n
```

Где:
- **Nu** - число Нуссельта
- **Re** - число Рейнольдса
- **Pr** - число Прандтля
- **C, m, n** - эмпирические константы

Корреляция Вошни (Woschni):
```
h = 3.26 · B^(-0.2) · p^0.8 · T^(-0.55) · w^0.8
```

Где:
- **h** - коэффициент теплоотдачи (Вт/(м²·К))
- **B** - диаметр цилиндра (м)
- **p** - давление (Па)
- **T** - температура (К)
- **w** - характерная скорость газа (м/с)

### Скорость поршня

Мгновенная скорость поршня:
```
v_p = ω · r · (sin(θ) + (r/2l) · sin(2θ))
```

Где:
- **ω** - угловая скорость коленвала (рад/с)
- **r** - радиус кривошипа (м)
- **l** - длина шатуна (м)
- **θ** - угол поворота коленвала

### Потери тепла через стенки

Поток тепла:
```
Q̇ = h · A · (T_gas - T_wall)
```

Где:
- **Q̇** - поток тепла (Вт)
- **h** - коэффициент теплоотдачи
- **A** - площадь поверхности теплообмена
- **T_gas** - температура газа
- **T_wall** - температура стенки

## Математические модели детонации

### Индекс детонации (KI)

Индекс Кнудсена-Икеды:
```
KI = (p_max / p_ignition) · (τ_ignition / τ_cycle)
```

Где:
- **p_max** - максимальное давление сгорания
- **p_ignition** - давление в момент зажигания
- **τ_ignition** - время задержки воспламенения
- **τ_cycle** - время цикла

Критическое значение:
```
KI_crit ≈ 1.5 - 2.0
```

### Энергия активации детонации

```
E_det = E_ignition + ΔH_combustion · φ
```

Где:
- **E_det** - эффективная энергия активации детонации
- **E_ignition** - энергия активации зажигания
- **ΔH_combustion** - теплота сгорания
- **φ** - фактор усиления (зависит от турбулентности)

## Законы подобия

### Число Маха

```
Ma = v / c
```

Где:
- **v** - скорость потока
- **c** - скорость звука

Критическое число Маха для сгорания:
```
Ma_comb_crit ≈ 0.3 - 0.5
```

### Число Рейнольдса

```
Re = (ρ · v · L) / μ
```

Где:
- **ρ** - плотность
- **v** - скорость
- **L** - характерный размер
- **μ** - динамическая вязкость

Типичные значения в двигателе:
```
Re ≈ 10^4 - 10^6
```

## Термодинамический КПД

### Теоретический КПД цикла Отто

```
η_otto = 1 - (1 / r^(γ-1))
```

Где **r** - степень сжатия.

Пример для r = 10 и γ = 1.4:
```
η_otto = 1 - (1 / 10^0.4) = 1 - 0.398 = 0.602 (60.2%)
```

### Реальный КПД с учётом потерь

```
η_real = η_otto · η_combustion · η_mechanical · η_heat
```

Типичные значения:
- **η_combustion** = 0.95 - 0.98 (полнота сгорания)
- **η_mechanical** = 0.85 - 0.90 (механический КПД)
- **η_heat** = 0.70 - 0.80 (учёт теплопотерь)

Реальный КПД:
```
η_real ≈ 0.60 · 0.96 · 0.88 · 0.75 ≈ 0.38 (38%)
```

## Математическое моделирование фаз сгорания

### Функция Вибе (Wiebe function)

Доля сгоревшего топлива:
```
x(θ) = 1 - exp(-a · ((θ - θ_0) / Δθ)^(m+1))
```

Где:
- **x** - доля сгоревшего топлива (0 - 1)
- **θ** - текущий угол ПКВ
- **θ_0** - угол начала сгорания
- **Δθ** - продолжительность сгорания (в градусах ПКВ)
- **a** - параметр формы (обычно a = 5)
- **m** - параметр формы (обычно m = 2 - 3)

Скорость сгорания:
```
dx/dθ = (a · (m+1) / Δθ) · ((θ - θ_0) / Δθ)^m · exp(-a · ((θ - θ_0) / Δθ)^(m+1))
```

### Масса сгоревшего топлива

```
m_burned(θ) = m_fuel_total · x(θ)
```

### Скорость выделения тепла

```
dQ/dθ = m_fuel_total · Q_LHV · dx/dθ
```

Где **Q_LHV** - низшая теплота сгорания топлива.

## Уравнения состояния продуктов сгорания

### Уравнение состояния реального газа

```
(p + a/V²) · (V - b) = R·T
```

Где:
- **a** - параметр притяжения молекул
- **b** - собственный объём молекул

Для продуктов сгорания бензина:
```
a ≈ 0.5 - 1.0 Па·м⁶/моль²
b ≈ 3·10⁻⁵ м³/моль
```

### Коэффициент сжимаемости

```
Z = (p · V) / (R · T)
```

Для идеального газа: Z = 1
Для продуктов сгорания при высоком давлении: Z = 1.05 - 1.15

## Математические основы управления зажиганием

### Передаточная функция системы зажигания

```
G(s) = K · (τ·s + 1) / (τ₁·s + 1) · exp(-τ_d·s)
```

Где:
- **K** - коэффициент усиления
- **τ** - постоянная времени опережения
- **τ₁** - постоянная времени запаздывания
- **τ_d** - чистое запаздывание

### Частотная характеристика

Амплитудно-частотная характеристика:
```
|G(jω)| = K · √((τ·ω)² + 1) / √((τ₁·ω)² + 1)
```

Фазо-частотная характеристика:
```
φ(ω) = arctan(τ·ω) - arctan(τ₁·ω) - τ_d·ω
```
