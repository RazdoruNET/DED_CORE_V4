# Встроенный интерфейс DED CORE V4

Angular-приложение, которое лежит в LittleFS блока и открывается по
`http://192.168.4.1/` (а при установленном сертификате — и по
`https://core.dedbox.pro/`).

Раньше в `data/` лежал старый Angular-бандл от предыдущей версии: он не умел
домашнюю сеть, OTA, сертификат и диагностику и занимал ~930 КБ. Здесь тот же
интерфейс переписан под V4, без сторонних библиотек и тяжёлых графиков.

## Сборка

```bash
cd web
./build.sh
```

Скрипт ставит зависимости при первом запуске, собирает production-бандл и
заменяет `../data/`. Дальше — обычная заливка файловой системы:

```bash
cd ..
./flash-device.sh -p /dev/cu.usbserial-0001 --fs-only
```

## Разработка

```bash
npm start        # ng serve на http://localhost:4200
```

Dev-сервер не проксирует API блока: для живой проверки удобнее открыть
`http://192.168.4.1/` с телефона или собрать и залить `data/` на блок.

## Структура

| Файл | Что делает |
|---|---|
| `src/app/core/device.service.ts` | WebSocket-телеметрия, HTTP-запросы, команды блока |
| `src/app/core/models.ts` | Кадры и структуры API |
| `src/app/pages/dashboard` | Приборы, графики оборотов и дросселя |
| `src/app/pages/map` | Чтение, правка и запись карты зажигания |
| `src/app/pages/settings` | Отсечка, угол, датчики, серво, метка ротора |
| `src/app/pages/network` | Точка доступа, домашняя сеть, OTA, TLS, привязка |
| `src/app/pages/diagnostics` | Состояние блока, перезагрузка, режим диагностики |
| `src/app/ui/chart.component.ts` | SVG-график без внешних зависимостей |

## Ограничения каналов

- По HTTP (порт 80) доступны все маршруты: `/status`, `/wifi/*`, `/ota/*`,
  `/api/update`, `/api/tls`, `/api/provision`.
- По HTTPS (443) сервер отдаёт статику, `/api/status`, `/api/tls` и `/ws`;
  проверка OTA, загрузка прошивки и привязка — только по HTTP-странице
  `http://192.168.4.1/update`. Интерфейс сам показывает ссылку в HTTPS-режиме.
- Правка карты и настроек идёт по WebSocket: на HTTPS это `wss://<host>/ws`,
  на HTTP — `ws://<host>:81/`.
